# Pattern Forge

Pattern Forge is a full-stack application for generating code based on design patterns. The project combines a Spring Boot backend with an Angular frontend and lets you:

- choose a design pattern,
- fetch its configuration,
- generate code from user-provided parameters,
- use the AI generator,
- download generated files as a ZIP archive.

## Technology Stack

- **Backend:** Java 21, Spring Boot 3.4.x
- **Frontend:** Angular 19
- **Template engine:** FreeMarker
- **AI:** Spring AI + OpenAI

## Supported Patterns

The application supports the following patterns:

- Adapter
- Composite
- Observer
- Memento
- Factory Method
- Singleton

## Supported Languages

- Java
- C++

## Project Structure

- `backend/` - Spring Boot application and code generation logic
- `frontend/` - Angular application with the user interface
- `backend/src/main/resources/templates/` - code templates for patterns and languages
- `backend/src/main/resources/prompts/` - prompt used by the AI generator

## Requirements

- Java 21
- Maven Wrapper or Maven
- Node.js and npm
- An OpenAI API key if you want to use the AI generator

## Configuration

The backend requires the following environment variable:

- `SPRING_AI_OPENAI_API_KEY`

PowerShell example:

```powershell
$env:SPRING_AI_OPENAI_API_KEY="your_api_key"
```

The frontend talks to the backend using the base URL defined in:

- `frontend/src/environments/environment.ts`

By default, it is:

- `http://localhost:8080/api/v1`

## Running the Application

### 1. Backend

From the `backend/` directory, run:

```powershell
./mvnw spring-boot:run
```

On Windows, you can also use:

```powershell
mvnw.cmd spring-boot:run
```

The backend runs on port `8080` by default.

### 2. Frontend

From the `frontend/` directory, run:

```powershell
npm install
npm start
```

The application is usually available at:

- `http://localhost:4200`

## API

### Get pattern configuration

```http
GET /api/v1/patterns/{patternName}/config
```

Returns the data required to configure the generator for a selected pattern.

### Generate code from templates

```http
POST /api/v1/code-generator/generate
```

Accepts a pattern context object and returns a list of generated files.

### Generate code with AI

```http
POST /api/v1/code-generator/ai/generate
```

Accepts a problem description and returns generated files together with the recognized pattern name.

### Download generated files as a ZIP archive

```http
POST /api/v1/zip-generator/download
```

Accepts a list of generated files and returns a `pattern.zip` archive.

## How to Use the App

1. Start the backend.
2. Start the frontend.
3. Select a pattern from the menu.
4. Fill in the configuration parameters.
5. Generate the code.
6. Optionally use **Generate with AI**.
7. Review the generated files and download them as a ZIP archive.

## Troubleshooting

- If AI generation does not work, check `SPRING_AI_OPENAI_API_KEY`.
- If the frontend cannot reach the backend, make sure the backend is running on `8080` and that `environment.ts` points to the correct address.
- If you run into frontend dependency issues, delete `node_modules` and run `npm install` again.
